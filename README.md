# AEPIFY — ChatGPT Ads Management for SMBs & Service Businesses

> **Turn buyer conversations into high-converting ChatGPT Ads campaigns.** Built for global SMBs and high-consideration service businesses.

![AEPIFY Banner](assets/logo-cropped.png)

---

## ⚡ Overview

Customers are increasingly using conversational AI to research, compare, and make purchasing decisions. **AEPIFY** bridges the gap between buying intent and commercial capture by placing targeted, relevant ChatGPT Ads directly in those decision-making flows.

- **Light & Fast**: Pure HTML5, modern CSS3, vanilla JavaScript. Zero framework bloat.
- **Visual First**: Interactive pipelines, visual shift comparisons, real campaign metrics, and an instant Opportunity Scanner.
- **Mobile Optimized**: Zero text clipping, responsive 2-column app grids, adaptive full-width touch targets, and a smooth animated drawer menu.

---

## 🚀 Key Features & Interactive Demos

1. **Hero Intent-to-Ad Pipeline**: Interactive 4-stage visual flow demonstrating how buyer prompts map to commercial opportunities and ChatGPT Ad placements.
2. **The Shift (Google vs. AI Intent)**: Interactive comparison highlighting the transition from cold keyword matching to multi-step AI decision journeys.
3. **Audience Intent Matcher**: 6 target verticals (Home Services, Luxury Travel, B2B Consulting, Professional Services, Local Businesses, Premium Services) with live scenario previews.
4. **The 5-Step System**: Clean milestone workflow from domain intelligence analysis to live campaign launch.
5. **Real Campaigns & Live Metrics**: Verified campaign case studies with dynamic counter animations and commercial signal tracking.
6. **The Continuous Loop**: Animated pulse loop displaying the Discover → Build → Launch → Learn → Expand methodology.
7. **Interactive Opportunity Scanner**: Live simulated audit tool showing the exact buyer problems and conversation angles AEPIFY identifies for any domain.
8. **Founding 10 Intake Modal**: Clean, frictionless conversion modal with zero layout shifts.

## 🛠️ Getting Started Locally

No build tools or package managers required. Simply open `index.html` in any modern browser, or run a lightweight local server:

```bash
# Python 3
python3 -m http.server 8000

# Or Node.js
npx serve .
```

Open `http://localhost:8000` in your browser.

---

## 🌐 Deploy to GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings** → **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your site will be live at `https://<username>.github.io/<repo-name>/` in under a minute!
